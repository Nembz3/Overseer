# Contributing to Overseer

Thanks for your interest in contributing to Overseer.

## Getting started

1. Fork the repository.
2. Clone your fork.
3. Install dependencies:

```bash
npm install
```

4. Create a branch for your change:

```bash
git checkout -b feature/my-feature
```

## Before submitting a pull request

Run the project's validation checks:

```bash
npm run check
```

Please make sure your changes:

- Keep the existing code style where practical.
- Do not commit secrets, tokens, `.env` files, or databases.
- Update documentation when behaviour changes.
- Update `CHANGELOG.md` for notable user-facing changes.
- Keep pull requests focused on a clear purpose.

## Pull requests

Describe what your change does and why it is useful. If you fixed a bug, include enough information for maintainers to understand the problem.

## Reporting bugs

Please use the bug report issue template and include steps to reproduce the problem.

Thank you for helping improve Overseer.

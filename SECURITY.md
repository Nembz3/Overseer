# Security Policy

## Supported version

Security fixes are provided for the latest release of Overseer.

## Reporting a vulnerability

Please do not publicly disclose security vulnerabilities in GitHub Issues.

Instead, contact the repository owner privately with:

- A description of the vulnerability.
- Steps to reproduce it.
- Potential impact.
- Any suggested mitigation, if available.

Please avoid including Discord bot tokens, Gemini API keys, or other secrets in reports.

## Security expectations

Contributors should never commit:

- `.env` files.
- Discord bot tokens.
- API keys.
- Production databases.
- Private credentials or personal data.

Security reports will be reviewed as quickly as reasonably possible.

# Overseer V3.0.0 Release Notes

**Release status:** Final planned feature release

## Highlights

- Gemini-powered AI administration
- Natural-language Overseer activation
- Smart AutoMod and moderation case tracking
- Warning history and safety controls
- Persistent SQLite-backed server memory
- Proactive join-flood and activity-spike detection
- Scheduled intelligence reports
- Private tickets with AI assistance and staff escalation
- Runtime diagnostics and quota-aware AI handling
- GitHub Actions validation and project documentation

## Maintenance policy

V3.0.0 is Overseer's final planned feature release.

Future updates should focus on bug fixes, security fixes, dependency compatibility, and critical reliability improvements.

New major features are not planned unless the project's direction deliberately changes.

Thank you to everyone who uses, tests, reports issues, or contributes to Overseer. ❤️

# Contributor Code of Conduct

## Our standards

We want the Overseer community to be welcoming and respectful.

Examples of positive behaviour include:

- Being respectful and constructive.
- Accepting feedback professionally.
- Focusing criticism on ideas and code rather than people.
- Helping create a friendly environment for contributors.

Examples of unacceptable behaviour include:

- Harassment or personal attacks.
- Discrimination or hateful conduct.
- Deliberately disrupting discussions.
- Sharing another person's private information without permission.

## Enforcement

Project maintainers may remove comments, issues, pull requests, or contributions that violate this code of conduct.

## Reporting concerns

If you experience unacceptable behaviour, contact the repository owner privately.
